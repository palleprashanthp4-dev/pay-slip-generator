## 💰 Salary Components

| Component            | Description                                               |
| -------------------- | --------------------------------------------------------- |
| **Basic Salary**     | Main salary component.                                    |
| **HRA**              | House Rent Allowance.                                     |
| **Allowances**       | Conveyance, LTA, special allowance and other earnings.    |
| **Employee PF**      | Employee provident fund contribution where applicable.    |
| **Employer PF**      | Employer contribution and not an employee deduction.      |
| **ESI**              | Employee and employer ESI contributions where applicable. |
| **Professional Tax** | State-specific professional tax where applicable.         |
| **TDS**              | Income-tax deduction where applicable.                    |
| **Net Salary**       | Gross earnings minus employee deductions.                 |

> **Note:** PF, ESI, Professional Tax, TDS and other statutory rules can change. Always verify the current applicable rules before using figures for official payroll or compliance purposes.

## ❓ FAQ

### Is it free?

Yes.

### Is there a watermark?

The generated payslip is designed to provide a clean document without a distracting watermark.

### Does it require an account?

No account is required.

### Does it upload salary information?

The application is designed for browser-based processing, so salary information does not need to be uploaded to a payroll server.

### Can I customize salary components?

Yes. You can add different earnings and deductions according to the salary structure.

### Should employer PF be deducted from employee salary?

No.

The employer's PF contribution is an employer cost. The employee's applicable PF contribution is the employee-side deduction.

### Can I generate multiple payslips?

Yes. Generate each employee's payslip separately and download the resulting PDF.

### Can a generated payslip be used for official purposes?

A payslip should contain genuine employment and salary information and should be issued or verified by the employer.

Never fabricate or alter salary information for loans, visas, rentals, or other official applications.
